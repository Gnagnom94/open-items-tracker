# Open Items Tracker

Visualize and interact with your `open-items.md` backlog — generated by the [open-items-tracker](https://github.com/Gnagnom94/open-items-tracker) AI agent skill — directly inside VS Code.

## Features

- **Sidebar view** — persistent Activity Bar icon; always one click away
- **Central panel** — full-width view via Command Palette
- **Live parsing** — reads and renders `docs/open-items.md` with full module/section structure
- **Checkbox interaction** — check/uncheck items directly in the panel; changes write back to the `.md` file instantly
- **Auto-refresh** — file watcher re-renders the panel on every save, no reload needed
- **Search & filter** — filter by status (Open / Partial / Done / Future) or free-text search across all items
- **Progress indicators** — global progress bar + per-module mini-bar show completion at a glance
- **Collapsible modules** — accordion cards keep the view clean on large backlogs
- **Responsive layout** — two-column grid on wide panels, single column in the sidebar
- **Theme-aware** — uses VS Code CSS variables; works with any light, dark, or high-contrast theme

## Generating the Backlog

To generate the `open-items.md` file that this extension parses, you must use the AI agent skill included in this repository.

1. Locate the `skill/open-items-tracker.md` file inside this repository.
2. Install or load this skill into your preferred AI coding assistant (e.g., Antigravity).
3. Ask the assistant to "generate the open items backlog". The skill will automatically scan your project's formal documentation and codebase to produce the correctly formatted markdown file.

## Loading a File

Three ways to point the extension at your `open-items.md`:

| Method | How |
|---|---|
| **Auto-discover** | Place the file at `docs/open-items.md` in your workspace root — loaded automatically |
| **Active editor** | Open the file in an editor tab, then click the 📄 button in the panel header |
| **File picker** | Click the 📂 button in the panel header to browse |

To reset back to the empty state, click the **✕** button in the panel header.

The chosen path persists across VS Code sessions (stored in workspace state).

## Commands

| Command | Description |
|---|---|
| `Open Items Tracker: Show Panel` | Open the full-width central panel |

The sidebar view opens automatically from the Activity Bar (circle icon, left rail).

## Item Format

The extension parses the following markdown format (see [`open-items.md`](open-items.md) for a full example):

```markdown
## 📋 Module Name

Brief context about this module.

### Sub-section Title

- [x] ~~**Completed item**~~ — done (2024-03-15). Reference note.
- [ ] **Open item** — context on what's needed.
- [ ] **Partial item** 🔄 — what's done and what remains.
- [ ] **Future item** 🔮 — scoped for a later phase.
```

Checking a checkbox in the panel converts an open item to:
```markdown
- [x] ~~**Item text**~~ — done (2025-06-01).
```

Unchecking restores it to:
```markdown
- [ ] **Item text**
```
