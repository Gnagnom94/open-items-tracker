# Open Items Tracker

![Coverage](https://img.shields.io/endpoint?url=https://gist.githubusercontent.com/Gnagnom94/4f69766e75314dcf93001617709abcf8/raw/open-items-tracker-coverage.json)

Visualize, edit, and manage your `open-items.md` backlog — generated by the [open-items-tracker](https://github.com/Gnagnom94/open-items-tracker) AI agent skill — directly inside **VS Code**, **Cursor**, **Windsurf**, and **Antigravity IDE**.

## Features

### Views

- **Sidebar** — persistent Activity Bar icon; open in one click from any workspace
- **Custom Editor** — open any `.md` file with the Open Items panel directly as an editor tab (right-click → "Reopen Editor With…" → Open Items Tracker, or use the action bar button)
- **Action bar button** — a "Show Panel" button appears automatically in the editor title bar when the active markdown file contains open-items syntax
- **Central panel** — full-width view via Command Palette (`Open Items Tracker: Show Panel`)
- **Responsive layout** — CSS Grid stats, wrapping toolbar, and compact elements adapt to any width (sidebar, split pane, or full editor)
- **Theme-aware** — uses VS Code CSS variables; works with any light, dark, or high-contrast theme

### Parsing & Display

- **Live parsing** — reads `open-items.md` and renders modules, sub-sections, and items with full hierarchy
- **Auto-refresh** — file watcher re-renders on every save, no manual reload needed
- **Stats dashboard** — six stat cards (Total, Done, Partial, Open, Future, % Complete) with accent-colored borders and hover animations
- **Progress indicators** — global progress bar + per-module mini-bar
- **Collapsible modules** — accordion cards keep large backlogs clean
- **Clickable markdown links** — `[text](path)` links in items and notes open the target file in the editor; supports `#L10-L20` line-range navigation and `file:///` URIs

### Git Integration (Live Diff Visuals)

- **Git Status Panel** — shows overall repository status (clean / modified) with change counts (added, modified, deleted) in a themed badge bar.
- **Status Gutter Highlights** — line-level status (added, modified, deleted) using left border markers and theme-native colors.
- **Word-Level Inline Diffs** — highlights internal changes (green insertions and red strikethrough deletions) inside edited item texts and descriptive notes.
- **Deleted Items List** — displays items deleted relative to `HEAD` as readable red strikeout items at the bottom of lists.
- **Hybrid Fuzzy Matching** — dynamically matches moved and slightly edited items (using Levenshtein + Jaccard word similarity) to preserve diff context when lines are reordered.

### Undo / Redo History

- **Shortcuts Support** — Intercepts `Ctrl+Z` / `Ctrl+Shift+Z` / `Ctrl+Y` in the webview to revert/redo local backlog updates.
- **External Edit Watcher** — Auto-detects manual file saves in your workspace and resets the redo stack to prevent code divergence.

### Editing (all changes write back to the `.md` file instantly)

- **Checkbox toggle & badges** — check/uncheck any item, or use the interactive status dropdown selector (Open, Partial, Future, Done) to transition states.
- **Inline text edit** — click to edit:
  - Item text
  - Item note (the description below the item)
  - Module name
  - Module context description
  - Sub-section title
- **Add items** — `+ Add item` button at the bottom of every list (including empty ones)
- **Add sub-sections** — `+ Add sub-section` button at the bottom of each module
- **Add modules** — `+ Add module` button below the grid
- **Delete** — hover any item, module, or sub-section to reveal a `×` delete button

### Sorting & Filtering

- **Sort strategies** — dropdown selector per session:
  - As in file (manual order)
  - By status (open → partial → future → done)
  - Alphabetical
  - Done last / Done first
- **Filter tabs** — All / ⬜ Open / 🔄 Partial / ✅ Done / 🔮 Future
- **Free-text search** — instant filter across all item text and notes

### Font Size

- **Toolbar controls** — A− (decrease), A (reset), A+ (increase) buttons in the panel header
- **Separate settings** — sidebar and custom editor have independent font size values
- **Persistent** — saved in VS Code settings, survives restarts

### Reordering (drag & drop, writes to file)

- **Items** — drag the `⋮` handle to reorder within any list
- **Sub-sections** — drag the `⋮` handle to reorder within a module
- **Modules** — drag the `⋮` handle to reorder modules in the grid

## AI Skill Integration

The extension bundles the `open-items-tracker` AI agent skill and can install it automatically into your AI coding assistant.

### Auto-install on activation

On first activation, the extension detects your IDE and prompts you to install the skill to the correct location:

| IDE             | Skill path                                    |
| --------------- | --------------------------------------------- |
| VS Code         | `~/.claude/skills/open-items-tracker/`        |
| Cursor          | `~/.claude/skills/open-items-tracker/`        |
| Windsurf        | `~/.claude/skills/open-items-tracker/`        |
| Antigravity IDE | `~/.gemini/config/skills/open-items-tracker/` |

Choose **Install** to copy `SKILL.md` automatically, **Not Now** to be reminded next session, or **Don't Ask Again** to suppress the prompt permanently.

### AI Skill Status & Install command

Use **Open Items Tracker: AI Skill Status & Install** (Command Palette, sidebar toolbar icon, or the 🧩 button in the panel header) at any time to:

- See whether the skill is installed and where
- Install or reinstall it with one click
- Open the skill folder in your OS file manager
- Re-enable the startup install prompt after "Don't Ask Again"

### Manual installation

1. Locate `skills/open-items-tracker/SKILL.md` inside this extension's install folder (or clone the repository)
2. Copy it to the path for your IDE (see table above)
3. Ask your AI assistant: _"generate the open items backlog"_

The skill scans your project's formal documentation and codebase to produce a correctly formatted `docs/open-items.md`.

## Loading a File

| Method             | How                                                                      |
| ------------------ | ------------------------------------------------------------------------ |
| **Auto-discover**  | Place the file at `docs/open-items.md` — loaded automatically on startup |
| **Custom Editor**  | Right-click any `.md` → "Reopen Editor With…" → Open Items Tracker       |
| **Action bar**     | Click the 📋 button in the editor title bar on any open-items `.md` file |
| **Active editor**  | Open the file in an editor tab, click the ↙ button in the sidebar header |
| **File picker**    | Click the … button in the sidebar header to browse                       |
| **OS drag & drop** | Drag the file from your OS file manager onto the sidebar                 |

Click **🗑** in the sidebar header to clear the tracked file and return to the empty state. The chosen path persists across sessions.
Click **Raw ↗** to open the raw markdown file in the standard text editor.

> **Note:** Dragging from VS Code's Explorer panel does not work due to internal sandboxing. Use the OS file manager (e.g. Windows Explorer) for drag & drop, or the Active Editor / File Picker buttons instead.

## Settings

Open Settings (`Ctrl+,`) and search for **Open Items Tracker**:

| Setting                                 | Default  | Description                                                                                                      |
| --------------------------------------- | -------- | ---------------------------------------------------------------------------------------------------------------- |
| `openItemsTracker.defaultSort`          | `manual` | Default sort order for items: `manual`, `status`, `alpha`, `done-last`, `done-first`                             |
| `openItemsTracker.collapseByDefault`    | `false`  | Collapse all module accordions when the panel opens                                                              |
| `openItemsTracker.showDoneItems`        | `true`   | Show / hide completed items                                                                                      |
| `openItemsTracker.showFutureItems`      | `true`   | Show / hide future-phase items                                                                                   |
| `openItemsTracker.fontSizeSidebar`      | `12`     | Base font size (px) for the Sidebar panel                                                                        |
| `openItemsTracker.fontSizeEditor`       | `13`     | Base font size (px) for the Custom Editor panel                                                                  |
| `openItemsTracker.gitIntegration`       | `true`   | Enable real-time Git status and modifications visualization                                                      |
| `openItemsTracker.gitHighlight`         | `true`   | Highlight modified, added, and deleted items using Git diff status                                               |
| `openItemsTracker.gitShowInlineDiff`    | `true`   | Show inline word-level text differences inside modified items                                                    |
| `openItemsTracker.undoRedoStackSize`    | `50`     | Maximum number of undo steps to retain in history                                                                |
| `openItemsTracker.promptSkillInstall`   | `true`   | Show the one-time prompt to install the AI skill on activation                                                   |
| `openItemsTracker.skillPathClaudeCode`  | _(auto)_ | Override the skill install path for VS Code / Cursor / Windsurf. Default: `~/.claude/skills/open-items-tracker/` |
| `openItemsTracker.skillPathAntigravity` | _(auto)_ | Override the skill install path for Antigravity IDE. Default: `~/.gemini/config/skills/open-items-tracker/`      |

## Item Format

The extension parses the markdown format produced by the `/open-items-tracker` skill (see [`open-items.md`](open-items.md) for a full example):

```markdown
## 📋 Module Name

Brief context about this module.

### Sub-section Title

- [x] ~~**Completed item**~~ — done (2025-06-01). Reference note.
- [ ] **Open item** — context on what's needed.
- [ ] **Partial item** 🔄 — what's done and what remains.
- [ ] **Future item** 🔮 — scoped for a later phase.
```

**Checkbox interactions:**

| Action              | Result in file                            |
| ------------------- | ----------------------------------------- |
| Check an open item  | `- [x] ~~**text**~~ — done (YYYY-MM-DD).` |
| Uncheck a done item | `- [ ] **text**`                          |
| Click text          | Edit item text inline                     |
| Click note          | Edit note inline                          |
